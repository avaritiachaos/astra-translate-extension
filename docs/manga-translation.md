# 漫画图片翻译使用说明

当前支持手动单图、可见相邻双页，以及主动开启的连续阅读翻译，已在 Chromium 浏览器中验证。最低支持 Chrome 116；建议使用当前稳定版浏览器。开发构建使用 Node 24。

## 配置 CPA 和模型

1. 如果主翻译／聊天已经配置了可用的 OpenAI 兼容服务商，可以保留这套地址、客户端 Key 和请求头，无需再填一份 Key。尚未配置 CPA 时，可在服务商设置中选择 Custom OpenAI-compatible，填写 CPA 的客户端 API Key。
2. 本机 CPA 的 Base URL 填 `http://localhost:8317/v1`，Endpoint 填 `/chat/completions`。`management.html#/quota` 是管理页面，不是模型接口。
3. 在“漫画翻译”卡片选择“跟随当前服务商”，或明确选择另一套已经配置的服务商。点击“读取可用模型”，从接口返回的完整 ID 中选择识图模型，并选择目标语言。模型列表不代表每个模型都支持图片，仍需验证识图能力；不支持列表的接口可以手动填写真实模型 ID。
4. 点击“验证识图能力”。插件会生成一张包含随机文字的测试图，检查模型是否正确读取图片及返回完整结果；固定的文字回答不能通过验证。

漫画模型独立于聊天模型。处理中修改设置不会改变已经发出的任务。管理页面登录密钥与客户端 API Key 用途不同，不应混用。

## HTTP 400 与 CPA 的模型 ID

2026-09-09 在用户授权的本机 CPA 上确认：

- `gemini-3.8-flash` 返回 HTTP 400，错误为 `unknown provider for model gemini-3.8-flash`，并带 `model_not_found` 错误码。
- 同一个接口的模型列表实际提供 `gemini-3.8-flash-high`；使用这个完整 ID 时，原有图片、流式返回和 JSON Schema 请求均成功，不需要删除图片或降低结构化结果要求。
- 随机识图验证通过，真实少年ジャンプ＋双页分别返回 12 和 8 个文字区域。此结果只对应当时该 CPA 的模型路由；其他服务商或以后变化后的 ID 必须以接口列表为准。

新配置不再预填猜测的漫画模型。已保存的模型不会静默替换；若仍是旧的 `gemini-3.8-flash`，读取列表后明确选择 `gemini-3.8-flash-high`（若该 ID 仍在你的接口列表中），回到漫画重试。模型选择立即保存；不是单纯点击重试就能修复一个不存在的 ID。

插件会把模型不存在的 HTTP 400/404 显示为“接口不识别模型”，并在页内提供“设置漫画翻译”入口。它不会因为此错误改换供应商、借用其他 Key、删除图片或无意义地重发同一个无效模型请求。其他类型的 400 仍需根据实际原因排查，不能都当作模型 ID 问题。
## 能选中，但提示没有 API Key

这表示漫画所选的服务商配置不完整，不一定代表插件里的所有服务商都没有 Key。早期版本把漫画默认固定到 Custom OpenAI-compatible；主翻译已经配置 Google Gemini 或其他服务商时，漫画仍可能选中了空的 Custom 配置。

1. 点击页内错误卡片的“设置漫画翻译”，直接进入漫画配置。
2. 若当前主服务商就是需要复用的识图服务，点击“使用当前服务商”，或选择“跟随当前服务商”；若需另一套服务，选中那套已配置的服务商。
3. 核对卡片显示的服务商、请求地址和漫画模型；确认“验证识图能力”通过后回到漫画点击“重试”。识图模型必须是这套服务商实际提供的模型，不能只因 Key 已配置就假定模型可用。

新安装或没有独立漫画配置的旧设置默认跟随当前服务商。已有明确选择保持不变，不会为了消除报错而偷偷改请求地址或借用另一服务商的 Key。漫画服务商切换会立即保存，文本编辑仍自动保存；真正没有 Key 时，仍需在对应服务商设置中填写，不要把 Key 发到聊天中。

配置预检在读取图片／截图之前完成；缺少 Key、地址、模型或接口不兼容时，完整显示原因与设置入口，不创建翻译任务。主服务商的 Key、地址和请求头按同一套配置一起使用，漫画模型和目标语言保持独立。
## 翻译和对照

- 弹窗现在将“网页文字”和“图片翻译”分开。“翻译网页文字”处理网页中的文本；“翻译当前图片”自动识别当前主要图片／相邻双页并直接开始；“选择图片…”先打开选图器，点击后才开始。也可右键图片选择“使用 Astra 翻译这张图片”。
- 进入选图后，可点击单页；若识别到同一阅读器中的相邻双页，也可点击“翻译本屏双页”。悬停此按钮会同时预览两页边框。这是明确选择的最多两张可见图片，不会扫描或上传整章。选择期间会阻止翻页误触，Esc 或“取消”退出。
- canvas 总是只截取所选画布当前可见的部分，并标记“仅可见区域”；选框、裁剪和译文都遵守阅读器的滚动裁剪边界。
- 译文优先在气泡内排版，细长的中文／日文内容使用真正的竖排列。按实际文字宽高选择字号，放不下或背景不可靠的区域改为小圆点，有可用候选译文的不确定区域可直接显示并注明待确认；不会自动撑出气泡或缩成难以阅读的小字。点击任何译文或圆点，在独立对照卡里查看全文和原文，Esc 或点击卡片外关闭。
- 阅读控件默认收起为小按钮，点击“展开漫画工具栏”后显示操作。展开后底部只有一条阅读栏。“查看原图”同时切换当前阅读会话中的译文；右侧 × 恢复全部并取消尚未完成的任务。点击完成数量／错误提示，可查看各页进度、单独重试、恢复，或直接进入漫画设置。重试会强制请求，不复用旧结果。
- 恢复后再次翻译相同图片，会优先读取匹配的本地缓存。
- 长条图会按原图坐标分块处理，逐块显示完成结果。
- 若原图因登录态或防盗链无法读取，插件会尝试截取选中图片的可见部分，并显示“仅可见区域”。这不会代表整张图片已经翻译完成。

加载开发构建时，在扩展管理页加载或重新加载 `dist` 目录，然后刷新漫画网页，让网页中的内容脚本更新。

### 当前页和选择图片的区别

- **翻译当前图片／当前页**：通常用于正在看的单页或双页。识别到合适图片就直接翻译；找不到时自动打开选图器，不再点击后毫无反馈。图片节点被翻页复用时，以实际图片来源和页面地址判断，不把旧任务的“已完成”当作新页已译。
- **选择图片…**：用于同页有多张候选图、或者需要手动指定对象。仅进入选图不会发送图片，确认点击后才翻译。
- 主要按钮会显示“翻译中…”、“已翻译”或“重试本页”，不再用一个常驻“翻译本屏”按钮同时代表不同状态。“网页文字”则是另一项功能，不处理图内文字。
## 右键、阅读栏拖动和字号

- 选中文字时右键显示“使用 Astra 翻译选中文字”；图片右键显示“使用 Astra 翻译这张图片”；普通页面／canvas 区域保留“选择页面图片翻译…”入口。选图不再注册为 `all` 场景，避免图片和选中文字的菜单里总是多出另一项近似操作。Chrome 在同一场景匹配多项时仍可能自动合成扩展子菜单，不对浏览器原生菜单的组织方式作强制承诺。
- 阅读栏左端的 **⠿ 把手可以拖动**。位置保存在扩展自己的本地存储，刷新页面后保留；全屏切换或窗口缩小时会限制在可见范围内。拖到顶部时，详情／全部译文面板会在下方展开。双击把手或聚焦把手后按 Home 恢复默认位置，方向键可微调（Shift 加大步长）。
- 普通对白优先直接覆盖。检测到可靠气泡时，即使原文靠近气泡边缘，也可使用限于气泡内部的原文字框，而不是仅因不在保守的中心区域就折叠。中文译文遇到细长英文文字框也可以按框形竖排。
- 覆盖字号在 **12–28 CSS px** 内根据译文字数、文字框大小和实际浏览器测量自适应，空间充足时不再限制为 20px。不会为了塞进内容缩到不可读或让文字溢出。拟声词、未返回译文、没有可靠气泡的复杂背景和确实放不下的内容仍用标记。
- 标记优先放在文字框侧边，避开已检测的原文字框及其他标记；极端拥挤时按最少重叠选择位置，不声称能识别所有背景细节。可点击范围保持 **40×40px**，中间可见圆点为 26px；点在圆点附近的透明范围也会打开对照卡。按下后稍微移出范围再松开，也会拦住这一次点击，不把它交给网页翻页。
- 对照卡在空间允许时宽 400px、至少约 200px 高，译文字号为 18px。每次按当前内容重新测量：短句不需要不必要的滚动条，长文在视口范围内扩展。卡片会尽量避开拖动后的阅读栏，并显示在另一页的标记上方。

上述调整不会自动重新请求翻译，也不等于复杂背景无痕擦字；已获得的结果可直接使用新的显示与交互方式。
## 圆点是折叠显示，还是没有译文？

- **紫色数字**：已经有译文，但因字号空间、背景／气泡边界、拟声词或裁剪等原因折叠显示。悬停会显示具体原因和译文，点击可固定对照卡，Esc 关闭。
- **待确认译文**：模型已有候选文字且能安全放入气泡时直接显示，带淡色边框和 ? 提示，不再一律藏成圆点。仍需对照原文；放不下或不宜覆盖时才显示橙色数字。
- **灰色问号**：这处没有返回可用译文，不是已经翻译后被折叠。空译文不会计入“已译”数量。

底部的 **“全部译文”** 会集中列出当前可见页面中模型已返回的文字区域，包含正常覆盖的内容、折叠译文、不确定候选和暂无译文的区域，并显示原文及折叠原因。不用反复点每个数字，也不会因预览或查看列表再次请求模型。

阅读栏会分开统计已译、已译折叠、待确认和暂无译文。原图上**没有标记且列表中也没有**的文字，可能是模型尚未识别的内容；“任务完成”不等于确认原图每处文字都已识别。

折叠的防遮挡规则仍然保留，不会为了全部铺上译文而强行放大文字框、遮挡人物或把字号缩得不可读。鼠标离开预览会自动关闭；点击标记固定后的卡片可用 Esc、关闭按钮或点击画面空白关闭。切换原图和恢复时不会遗留预览或结果列表。
## 选图入口和全屏

- 弹窗的选图按钮会先检查网页连接。漫画脚本缺失或失效时，只补载独立的 `manga-content.js`，不会重新注入整套划词、聊天和悬浮球功能；确认选图器已显示后才关闭弹窗。
- 网站进入全屏且显示漫画图片/画布时，底部会出现“漫画翻译”入口。开始翻译后默认为约 107px 的小控件，不再持续横铺工具条；点击展开操作，移开一段时间或再次进入全屏后收起。手动模式可点“翻译当前页／翻译当前双页”；开启连续翻译后会跟随翻页处理。已完成或正在处理的页面不会重复请求。
- 也可以按 **Alt+M**，或在网页空白／canvas 区域右键选择 **“选择页面图片翻译…”**。快捷键可在 `chrome://extensions/shortcuts` 中调整；若被其他扩展占用，可直接使用按钮或右键菜单。
- 浏览器自身的 F11 全屏不一定触发网页 Fullscreen API；这种情况下可使用 Alt+M 或右键菜单。原有悬浮球的左键仍用于网页文字翻译，不会自动改成漫画翻译。
- 选框和译文会跟随网站进入/退出全屏。“取消”仅退出选图；Esc 在全屏中也可能先触发浏览器退出全屏。原图、重试和恢复控件不会把这次点击传给阅读器翻页处理。
- 全屏切换或缩放动画尚未结束时，截图保护可能提示页面发生变化。等画面稳定后点击“重试”；插件不会把位置已变化的截图当作成功结果。

普通网页上的连接失败会提示检查站点访问权限；浏览器设置页、扩展商店等不允许选图的页面会单独说明，不再统一显示“请在普通网页中使用”。更新开发构建后，仍建议重新加载 `dist` 并刷新页面一次，以更新所有入口。
## 连续翻译与预读一页

1. 在漫画上启动一次选图／翻译，点击收起的小控件展开工具栏，再打开“连续阅读”。
2. 打开 **“自动翻译”** 开关：当前标签页同一漫画的可见页面稳定约 600ms 后会自动处理，不必逐页再点。会使用当前漫画服务商的模型额度；默认关闭。
3. 如需提前准备下一页，可另行打开 **“预读下一页”** 开关。这会在当前页任务完成后，最多提前请求一张下一页图片，可能产生额外费用；只适用于能可靠取到下一页原图的阅读器。
4. 关闭 **“自动翻译”** 开关、恢复全部、关闭标签页或切换漫画可停止。授权 30 分钟后到期，需要重新开启；已发往服务商的请求仍可能计费，暂停不能撤回既有费用。

面板只保留两个开关、当前状态和一句额度提示。点击时显示“正在开启”，后台确认后开关才变为开启状态；连接失败、地址变化或超时会明确提示，不能把点击成功等同于已经生效。详细范围说明放在本文，不再常驻展开面板。

支持和限制：

- 当前页可用 `<img>` 或 `<canvas>`；canvas 需在翻页时发生可观察的尺寸重置、元素替换或位置变化。没有任何 DOM 变化的原地连续重绘不保证能自动识别。
- 同文档翻页／滚动，以及同章节的编号页 URL（例如 `/reader/book/7/` → `/reader/book/8/`，或 `?page=7` → `?page=8`）可继续。跨章节、跨站点或其他标签页不继承。
- 预读只用同一阅读器已加载的相邻编号 `<img>`，或当前页面明确提供的同章节下一页链接与稳定的主图标识。只解析返回页面中的该图片地址，不执行下一页脚本，不猜图片 URL，不扫描整章。
- 未显示的 canvas 不能用当前标签页截图得到，所以像少年ジャンプ＋这样的 canvas 阅读器仍是在翻页显示稳定后自动翻译，而非保证提前完成。不可读原图也不会在后台截图整屏代替。
- 翻到已预读的页面时会复用同一任务的结果；若预读还在处理中，会等待它，不再重复提交这一页。服务商配置变化后不使用旧配置的预读结果。
- 切到后台不开始新的自动任务。临时网络／超时／截图位置变化错误至多增加一次任务级重试；接口层自身的有限重试仍然存在，因此不等于总共只发送两次 HTTP 请求。单页内容失败显示“本页失败，翻页后继续”，不在原地反复请求；连续三个不同页面失败、或模型／Key／地址配置有误时暂停。失败面板显示简短原因与“重试本页”“重试并继续”或设置入口。快速连翻会跳过未稳定的中间页。
- 普通对白中已返回的“待确认”译文现在可以直接阅读；这不是把不确定结果当作正确答案，原文与提示仍可在对照卡查看。
## 当前边界

- 支持当前文档中的 `<img>` 和有明确边界的 `<canvas>`。canvas 使用可见区域截图，不读取受限原图；跨域 iframe 内部、CSS 背景图和复杂多层组合阅读器暂未适配。
- 双页由两个图片/画布组成时，可以分别选择左右页；一个画布中包含整幅跨页时，按整张画布处理，不自动拆页。自动整页/整章翻译、手动框选和图片导出仍属于后续阶段。
- canvas 的宽高重置或元素替换会清除旧覆盖；没有 DOM 变化的连续重绘不自动追踪，遇到这种阅读器时应恢复后重新选图。
- 旋转或复杂变换布局使用译文列表回退；不对复杂背景执行无痕擦字或重绘。
- 单图上限为 15 MiB、2400 万像素，最多 24 个切块；同时执行最多两个漫画任务。过大图片需要分段处理。
- 对于读不清的文字、拟声词和范围过大的识别结果，保留不确定标记或使用可展开的译文卡。
- 已使用用户授权的本机 CPA Gemini 在少年ジャンプ＋公开漫画页验证真实识图、双页翻译及排版，并保留合成图回归测试。尚未系统评测逐句准确性；换服务商或模型后仍需验证识图能力。

## 存储与隐私

- 模型只接收手动选择的图片，或你明确开启连续翻译／预读后在其范围内的页面，以及翻译指令和术语。漫画任务不读取聊天历史。
- 图片资源下载不携带模型 API Key 或自定义鉴权头。截图回退只将选中图片的裁剪区域发送给模型。
- 图片在扩展自己的 IndexedDB 中保存，会话存储只保存引用。图片缓存有 128 MiB 预算与 24 小时有效期；访问和写入时会淘汰过期或较旧的文件。
- 清空聊天会清理关联图片；后台启动时还会删除已经失去会话引用的聊天图片。
- 漫画结果缓存有 20 MiB / 200 条预算与 30 天有效期。缓存命中取决于图片、模型、语言、术语和配置；缓存被淘汰后需要重新调用模型。
- 弹窗聊天与各网页文档的聊天互相隔离。页内界面只显示当前文档自己的会话。

## 常见情况

| 情况 | 处理方式 |
| --- | --- |
| 提示 API Key 未配置 | 检查漫画所选服务商是否保存了 CPA 客户端 Key。 |
| 识图验证失败 | 确认模型实际支持图片，并核对 CPA 的模型别名和图片转发。 |
| 原图读取失败 | 滚动到图片可见的位置，再尝试截图回退。 |
| 任务中断 | 点击重试。已完成的完整结果可复用，未完成任务不会在重启后自动上传旧图片。 |
| 回复不完整或坐标无效 | 结果不会当作成功覆盖；重试或换用合适的识图模型。 |

完整设计见 [架构书](manga-translation-architecture.md)，当前验证记录见 [实施进度](manga-implementation-progress.md)。
