## ✨ 特徴

- **ミニマルデザイン** — 余計な UI なんかないの。翻訳に集中しなさいよね
- **選択翻訳** — テキストを選んだらすぐ翻訳できるの。フローティングボール + ドラッグ可能なポップアップ付きよ
- **右クリック翻訳** — コンテキストメニューからワンクリックで翻訳できるの。簡単でしょ？
- **ページ全体翻訳** — ワンクリックでページ全体を翻訳できるの。リアルタイム増分翻訳対応よ、中断も自由自在
- **プロバイダー非依存** — あんたの好きな OpenAI-compatible API なら何でも使えるの（DeepSeek、OpenAI、Groq とかね）
- **ダークモード** — システムテーマに自動追従するの。設定いじる必要なんてないわ
- **多言語 UI** — 中文 / English / 日本語 に対応してるの。あんたが日本語選べばいいでしょ
- **プライバシー最優先** — API Key はローカル保存、データ収集なんてしないの。安心しなさいよ

## 🚀 クイックスタート

### インストール

```bash
npm install
npm run build
```

1. Chrome で `chrome://extensions/` を開きなさい
2. 「デベロッパーモード」をオンにするの
3. 「パッケージ化されていない拡張機能を読み込む」をクリックして、`dist` フォルダを選択しなさい

簡単でしょ？あんたでもできるわよ♡

### 設定

1. 拡張アイコンをクリック → 設定を開くの
2. プロバイダープリセット（DeepSeek とか）を選択するか、カスタム設定しなさい
3. API Key を入力するの
4. 「接続テスト」をクリック — 成功したら自動保存されるわ。ありがたいでしょ？

## 📖 使い方

| 操作 | 説明 |
|------|------|
| テキスト選択 | 翻訳アイコンが出て、クリックで翻訳できるの |
| 右クリックメニュー | 選択 → 「Translate selection with Astra」 |
| `Alt+T` | 選択テキストをショートカットで翻訳 |
| 拡張アイコン | ポップアップを開いて手動入力翻訳 |
| ページ全体翻訳 | ポップアップ下部 → 「現在のページを翻訳」 |

覚えるのは簡単でしょ？あんたの頭でも大丈夫よねぇ？

## 🛠 技術スタック

- **TypeScript** + **React 18**（Popup / Options）
- **Vanilla DOM**（Content Script、ゼロ依存よ）
- **Vite 5** ビルド
- **Chrome Manifest V3**

## 📁 プロジェクト構成

```
src/
├── background/     # Service Worker（メッセージルーティング、API 呼び出し）
├── content/        # Content Script（選択翻訳、ポップアップ、ページ翻訳）
├── popup/          # ポップアップ UI（React）
├── options/        # 設定ページ UI（React）
├── shared/         # 共有モジュール（型、ユーティリティ、i18n）
└── styles/         # テーマ変数
```

## 🔒 プライバシー

- 翻訳テキストはあんたが設定した API プロバイダーにだけ送信されるの
- 拡張機能はユーザーデータを収集・保存・送信なんてしないわ
- API Key は `chrome.storage.local` に保存されて、第三者に送信されることはないの
- パスワード入力欄とコードブロックは翻訳対象外よ。当然でしょ？
