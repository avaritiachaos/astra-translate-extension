## ✨ 特徴

ねぇおにいちゃん、ちゃんと読んでよね？あんたのために並べてあげたんだから感謝しなさいよ？

- **ミニマルデザイン** — 余計な UI なんかないの。翻訳に集中しなさいよね。おにいちゃんみたいなのでもわかるシンプルさよ
- **選択翻訳** — テキストを選んだらすぐ翻訳できるの。フローティングボール + ドラッグ可能なポップアップ付きよ。選択もできないザコはいないわよねぇ？
- **右クリック翻訳** — コンテキストメニューからワンクリックで翻訳できるの。簡単でしょ？ざこざこ～♡
- **ページ全体翻訳** — ワンクリックでページ全体を翻訳できるの。リアルタイム増分翻訳対応よ、中断も自由自在。おにいちゃんの英語力じゃ不要かもしれないけどね
- **プロバイダー非依存** — あんたの好きな OpenAI-compatible API なら何でも使えるの（DeepSeek、OpenAI、Groq とかね）。おにいちゃんの使い捨て API Key でも大丈夫よ？
- **ダークモード** — システムテーマに自動追従するの。設定いじる余計なことしなくていいわ。あんたには荷が重いだろうし
- **多言語 UI** — 中文 / English / 日本語 に対応してるの。おにいちゃん、日本語でいいでしょ？英語読めないんでしょ？
- **プライバシー最優先** — API Key はローカル保存、データ収集なんてしないの。あんたの API Key が盗まれたらあたしが困るだけだけどね♡

## 🚀 クイックスタート

### インストール

ねぇおにいちゃん、ここ大事だからメモしなさいよ？……メモしなくていいけど、ちゃんと読んどいてよね

```bash
npm install
npm run build
```

1. Chrome で `chrome://extensions/` を開きなさい。おにいちゃん、ブラウザくらい開けるわよね？
2. 「デベロッパーモード」をオンにするの。トグルスイッチよ？押せないザコはいないわよねぇ
3. 「パッケージ化されていない拡張機能を読み込む」をクリックして、`dist` フォルダを選択しなさい

簡単でしょ？あんたでもできるわよ♡ ざこざこ～♪ でも失敗したら笑うわよ？

### 設定

1. 拡張アイコンをクリック → 設定を開くの。おにいちゃん、Chrome の拡張アイコントレイの矢印、押せるわよねぇ？
2. プロバイダープリセット（DeepSeek とか）を選択するか、カスタム設定しなさい。おにいちゃん、API Key 持ってるの？持ってないなら……ざこねぇ♡
3. API Key を入力するの
4. 「接続テスト」をクリック — 成功したら自動保存されるわ。ありがたいでしょ？感謝しなさいよおにいちゃん

## 📖 使い方

おにいちゃん、ここが一番大事なんだから逃げないでよね？

| 操作 | 説明 |
|------|------|
| テキスト選択 | 翻訳アイコンが出て、クリックで翻訳できるの。おにいちゃんの英語力だと毎日お世話になるわよねぇ |
| 右クリックメニュー | 選択 → 「Translate selection with Astra」。右クリックくらいできるでしょ？ |
| `Alt+T` | 選択テキストをショートカットで翻訳。キーボード숏カットも覚えるおにいちゃんは偉いわね～偉いけどまだザコだけどね♡ |
| 拡張アイコン | ポップアップを開いて手動入力翻訳。おにいちゃんの力作訳文、見せてほしいわねぇ？（笑） |
| ページ全体翻訳 | ポップアップ下部 → 「現在のページを翻訳」。英語のサイト全部翻訳しちゃおうね？おにいちゃんには必要ないかもだけど |

覚えるのは簡単でしょ？あんたの頭でも大丈夫よねぇ？……たぶん♡

## 📁 プロジェクト構成

おにいちゃんの脳みそにも届くように、きれいに並べてあげるわね？

```
src/
├── background/     # Service Worker（メッセージルーティング、API 呼び出し）
```

## 🔒 プライバシー

ここは真面目に言うわよ？おにいちゃんの大事なデータなんだから、しっかり聞いてよね

- 翻訳テキストはあんたが設定した API プロバイダーにだけ送信されるの。あたしは見ないわよ？おにいちゃんの検索履歴なんて興味ないし♡
- 拡張機能はユーザーデータを収集・保存・送信なんてしないわ。おにいちゃんの個人情報、あたしが盗むわけないでしょ？……盗む価値ないしねぇ？ざこ♡
- API Key は `chrome.storage.local` に保存されて、第三者に送信されることはないの。おにいちゃんの API Key は安全よ。たぶん
- パスワード入力欄とコードブロックは翻訳対象外よ。当然でしょ？おにいちゃんの「password123」なんて翻訳されても困るだけだし
