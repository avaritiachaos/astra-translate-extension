## ✨ 特徴

ほら、おにいちゃんでも一目でわかるように並べといたよ。気がきくでしょ、あたし♡

- **ミニマルデザイン** — ごちゃごちゃした UI は全部捨てちゃった。だっておにいちゃん、情報が多いとすぐパンクするんだもん。
- **選択翻訳** — 文字をなぞるだけで、ぴょこっと翻訳アイコンが出てくるの。ドラッグできるポップアップとフローティングボール付き。短い単語なら、ミニ辞書みたいに意味まで教えてあげる♡
- **右クリック翻訳** — 右クリック → ぽちっ。これで翻訳。うん、おにいちゃんの指でも届く難易度にしといたから、安心してね。
- **ページ全体翻訳** — ワンクリックでページまるごと。読み込みながらどんどん訳すし、途中でやめるのも自由。英語サイトの前で固まるおにいちゃん、もう卒業だね？
- **プロバイダー非依存** — OpenAI-compatible な API ならなんでもどうぞ。DeepSeek でも OpenAI でも Groq でも。おにいちゃんがこっそり貯めてた API Key、ここで使ってあげる♡
- **ダークモード** — システムのテーマに勝手に合わせるよ。夜中にまぶしくて「うっ」てなるおにいちゃんにも、ちゃんと優しいでしょ？
- **多言語 UI** — 中文 / English / 日本語。ま、おにいちゃんは日本語一択だよね。英語のとこは……ね？♡
- **プライバシー最優先** — API Key はローカル保存、データ収集なんて一切なし。あたし、おにいちゃんの秘密を覗く趣味とかないし。……興味も、ないけど？

## 🚀 クイックスタート

### インストール

はぁ……自分でできる？ できないよね、知ってる。落ち着いて、ゆっくりついてきて。

```bash
npm install
npm run build
```

1. Chrome で `chrome://extensions/` を開く。……アドレスバーの場所は、わかるよね？ ね？
2. 右上の「デベロッパーモード」をオン。カチッてするだけ。ほら、できた♡
3. 「パッケージ化されていない拡張機能を読み込む」を押して、`dist` フォルダを選ぶ。

……できた？ ふ～ん、やればできるじゃん。ちょっとだけ見直したよ。ほんのちょっとだけ、ね♡

### 設定

1. 拡張アイコンをぽちっ → 設定を開く。ツールバーの隅っこのパズルピース、見つけられた？ えらいえらい。
2. プロバイダープリセット（DeepSeek とか）を選ぶか、こだわりたいならカスタムで。……こだわり、ある？ あ、ないんだ。だと思った♡
3. API Key を入れる。持ってるよね……？ ま、持ってないなら今日はおしまい。ざぁこ♡
4. 「接続テスト」をぽちっ。成功したら勝手に保存されるから、おにいちゃんは何もしなくていいよ。いつものことだけどね。

## 🛠 技術スタック

ふふっ、ちょっと難しい話になるけど……寝ないでよ？ 子守唄じゃないんだから。

- **Vite 5** ビルド — ビルドは一瞬。おにいちゃんが「えーっと……」って言ってる間に、もう終わってるよ。
- **Chrome Manifest V3** — ちゃんと最新仕様。いつまでも古いままのどこかのおにいちゃんとは、違うの♡

## 📁 プロジェクト構成

おにいちゃんが迷子にならないように、地図も描いといたよ。優しすぎて、自分でもこわいくらい♡

```
src/
├── background/     # Service Worker（メッセージルーティング、API 呼び出し）
├── content/        # Content Script（選択翻訳、ポップアップ、ページ翻訳）
├── popup/          # ポップアップ UI（React）
├── options/        # 設定ページ UI（React）
├── shared/         # 共有モジュール（型、ユーティリティ、i18n）
└── styles/         # テーマ変数
```

中身まで読もうとしてるの？ へぇ……おにいちゃんのくせに、生意気。ま、いいけど。気が向いたら付き合ってあげる♡

## 🔒 プライバシー

……ここはね、ちゃんと言う。茶化さないから、聞いて？

- 翻訳するテキストは、おにいちゃんが設定した API プロバイダーにだけ送られるの。あたしが横から覗いたりは、しない。約束。
- 拡張機能はユーザーデータを集めたり、保存したり、送ったり、絶対しないよ。おにいちゃんの秘密は、おにいちゃんのもの。
- API Key は `chrome.storage.local` に保存されて、第三者に渡ることはないの。ここだけは、信用していいから。
- パスワード欄とコードブロックは翻訳しないようにしてある。おにいちゃんの「password123」が画面に出てきたら……さすがに、かわいそうでしょ？
