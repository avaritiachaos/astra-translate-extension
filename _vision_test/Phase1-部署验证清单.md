# Phase 1 · 本地管线部署 + 验证清单

> 目标:在 3060 Laptop(6GB)上跑通完整漫画翻译管线(检测+OCR+消字+嵌字),
> 翻译接 mimo-v2.5,用真实漫画验证质量与显存占用。**这一步不碰插件代码。**
> 工具:[hgmzhn/manga-translator-ui](https://github.com/hgmzhn/manga-translator-ui)(基于 manga-image-translator 的一键 GUI)。
>
> 标注说明:✅=已查证;⚠️=文档未明说/需你实测确认,我给了兜底。

---

## 0. 前置检查(5 分钟)

- [ ] **GPU 驱动 ≥ 525**:命令行跑 `nvidia-smi`,看右上角 CUDA Version(要 12.x)和驱动版本。低了先去 NVIDIA 官网升级。
- [ ] **磁盘空间**:留 ~10GB(conda 环境 + 模型权重)。装到**非 C 盘**更省事,例如 `D:\manga-translator-ui\`。
- [ ] **网络**:首次安装要下 Miniconda/依赖/模型,确保能正常下载(必要时挂梯子)。

---

## 1. 安装一键包

repo 提供两种装法,任选:

- **方法一(脚本一键,推荐)**:下载 repo 里的 `.bat` 们,把 **`步骤1-首次安装.bat`** 放进目标目录(该目录即根目录)→ 双击运行。
  它会自动:装 Miniconda(~50MB)+ 便携 Git → clone 仓库 → 建 conda 环境(Python 3.12)→ **检测到 NVIDIA 自动装 CUDA 版 PyTorch** → 装依赖。
  > ⏳ 这步耗时较长(下载 + 编译),正常,耐心等它跑完。
- **方法二(免环境)**:若 release 提供打包版,解压后直接双击 `app.exe`。

- [ ] 安装脚本跑完无报错。

---

## 2. 首次启动

- [ ] 双击 **`步骤2-启动Qt界面.bat`** 打开界面。
- [ ] 首次翻译时会**自动下载检测/OCR/lama 模型**(⚠️ 大小文档没写,预计几百 MB~1GB+),第一次会卡一下,属正常。
- 以后更新:跑 `步骤4-更新维护.bat`;带更新启动用 `步骤3-检查更新并启动.bat`。

---

## 3. 配 mimo 翻译引擎 ✅(已查证可行)

进 **「API 管理」→「翻译」**,引擎选 **「高质量翻译 OpenAI」**(多模态,会把图一起发给模型 → mimo 能看画面,翻译更准):

| 字段 | 填什么 |
|---|---|
| API Key | 你的 mimo key |
| Base URL | `https://token-plan-cn.xiaomimimo.com/v1` |
| 模型 | `mimo-v2.5` |

- [ ] 三项填好。**Base URL 必须到 `/v1` 为止**(mimo 是 /v1,不是 /v3)。
- 兜底:多模态引擎若偶发抽风,改用普通 **「OpenAI」**引擎(纯文本)同样填这三项;翻译质量我们已验证 mimo 满分,纯文本也够用。

---

## 4. 配漫画管线参数(关键)

在设置/管线参数里(⚠️ 具体菜单名以界面为准),按漫画场景选:

- [ ] **检测器 detector**:`default` 或 `ctd`(comic-text-detector)。**❌ 别用 `craft`**(官方明说不适合漫画)。
- [ ] **OCR**:日文优先选 `mocr`(manga-ocr,日文专用);或默认 `48px`。
- [ ] **修复 inpainter**:`lama_large`(默认/推荐)。**❌ 别选 `sd`**(stable-diffusion,会爆 6GB 显存)。
- [ ] **源语言 = 日文,目标语言 = 简体中文**(⚠️ 语言选择 UI 位置文档没写,界面里找)。
- [ ] **GPU 开着**(NVIDIA 版默认开;别误关成 CPU,除非测对比)。

## 5. 跑测试图

- [ ] 准备测试图:我们测过的那页《スレイブの誕生》,或任意日文生肉(**用裁掉黑边的纯漫画图**)。
- [ ] 设输出目录 →「**添加图片**」→ 选刚配的译者 →「**开始翻译**」。
- [ ] 等出结果(第一次慢,在下模型)。

---

## 6. 质量验收清单(逐项打勾)

对着输出的成品图,一项项看:

- [ ] **检测**:每个气泡/旁白框都框到了?有没有漏框、或把两块串成一块?
- [ ] **OCR**:日文识别对不对?(重点看竖排、拟声词)
- [ ] **翻译**:mimo 译文准不准、地不地道?(已知它强,主要确认接通了)
- [ ] **消字 (inpainting)**:原文擦干净没?气泡底有没有残影/糊斑?彩色或网点背景处如何?
- [ ] **嵌字 (typesetting)**:译文排进气泡没?字号/换行/竖排顺不顺?有没有溢出框外?
- [ ] **整体**:把它当成品读一遍,能顺畅读懂剧情吗?
- 💡 哪里嵌字不完美 → 这 GUI **自带可视化编辑器**(移动/旋转文本框、手动改译、调样式),可手动修。

---

## 7. 记录显存占用(决定 6GB 够不够)

- [ ] 翻译进行中,开**任务管理器 → 性能 → GPU**,看「专用 GPU 内存」峰值;
      或命令行翻译时跑 `nvidia-smi` 看 `Memory-Usage` 峰值。
- [ ] 记下峰值数字。
  - 峰值明显 < 6GB → 舒服,甚至能开更大 inpainting_size 提质量。
  - 接近/超 6GB(OOM)→ 见下方排错。

---

## 8. 常见坑 + 排错

| 现象 | 处理 |
|---|---|
| **OOM / 显存爆 / CUDA out of memory** | inpainter 确认不是 `sd`;把 `inpainting_size`、`detection_size` 调小;实在不行个别阶段回退 CPU(慢但稳) |
| **mimo 连不上 / 401 / 404** | 查 Base URL 是否到 `/v1`、key 对不对、网络通不通 |
| **译文乱码 / 解析失败 / 漏译** | 多模态引擎偶发 JSON 问题 → 退回普通「OpenAI」引擎,或重试 |
| **第一次特别慢** | 在下模型 + 首次编译,正常;之后会快 |
| **启动报 PyTorch/CUDA 错** | 多半驱动太老,升级到 ≥525;或安装时 GPU 没被正确检测,重跑 `步骤1` |
