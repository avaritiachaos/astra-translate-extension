## 为什么是 Astra？

市面上的翻译插件，要么逼你登录、买会员、限次数，要么塞满广告。
Astra 反着来：**它不绑架你，只做一件事——把翻译做好。**

- 🔑 **用你自己的 API** —— 接入 DeepSeek 等大模型，按量付费，轻度使用充 1 块钱能用很久
- 🚫 **无登录 / 无会员 / 无广告** —— 装上填个 Key 就能用
- 💸 **翻过的永久缓存** —— 再遇到秒出，且不再消耗第二次费用
- 🎨 **翻译文风可调** —— 让 AI 用你喜欢的语气翻译，这是传统翻译引擎给不了的
- 🔒 **隐私优先** —— API Key 只存在你本地，不收集任何数据

## ✨ 功能特性

### 多种翻译方式
- **划词翻译** —— 选中文字即出悬浮球，一点就翻，弹窗可自由拖拽
- **右键翻译** —— 右键菜单一键翻译选中文本
- **快捷键** —— `Alt+T` 翻译当前选中内容
- **整页翻译** —— 一键翻译整个页面，边翻边看、随时可中断还原
- **手动翻译** —— 点开弹窗，粘贴任意文本即时翻译

### 智能省心（默认开箱即用）
- **智能目标语言** —— 选中英文自动翻成中文，选中中文自动翻成英文，无需手动切换方向
- **同语言纯度判断** —— 自动避免“中译中”这类无意义翻译，不浪费 token
- **软 / 硬内容保护** —— 自动识别链接、邮箱、路径、代码、哈希值并跳过；用户名 / ID 保持原样不被翻乱；密码输入框、代码块永不参与翻译
- **持久化缓存** —— 内置 SHA-256 去重缓存（默认 5000 条，LRU 淘汰），翻译过的内容秒出且零额外费用
- **实时增量翻译** —— 整页翻译时自动跟进动态加载、滚动懒加载出来的新内容

### 词典模式
选中单词或短语时，不只是翻译，还会给出 **词性、常见释义、当前语境说明、例句、发音**，并能识别人名 / ID 并保持原样——查词、背单词、读外刊的利器。

### 高度可定制
- **三套独立目标语言** —— 整页翻译、划词翻译、默认翻译可分别设定语言
- **自定义提示词（文风）** —— 划词与整页的翻译提示词均可编辑，调出正经、地道、活泼、学术等任意风格
- **界面随心调** —— 悬浮球大小 / 透明度、弹窗缩放、并发数、批量大小、超时、温度均可设置

### 服务商中立
支持任何 **OpenAI 兼容** 的 API（DeepSeek、OpenAI、Groq、本地模型等），自由填写 Base URL 与模型名。Gemini / Anthropic 适配规划中。

### 体验细节
- **三语界面** —— 简体中文 / English / 日本語
- **自动暗色模式** —— 跟随系统主题
- **设置自动保存** —— 改动即存，测试连接成功自动落盘
- **20 种目标语言** —— 中、英、日、韩、法、德、西、俄、阿拉伯语等

## 🚀 快速开始

### 方式一：使用打包好的安装包（推荐普通用户）

1. 下载随附的安装包并 **解压**（解压后会看到包含 `manifest.json` 的扩展文件夹）
2. 打开浏览器扩展页：Chrome 输入 `chrome://extensions`，Edge 输入 `edge://extensions`
3. 打开 **开发者模式**
4. 点击 **加载已解压的扩展程序**，选择解压出来的扩展文件夹

> ⚠️ 浏览器无法直接加载 `.zip`，请务必先解压再加载文件夹。

### 方式二：从源码构建（开发者）

```bash
npm install
npm run build
```

构建产物在 `dist/`，再按「方式一」的第 2–4 步加载 `dist` 文件夹即可。

### 配置 API

1. 点击扩展图标 →「打开设置」
2. **服务商预设** 选择 DeepSeek（或自定义 OpenAI 兼容服务）
3. 填入 **API Key**（DeepSeek 在 <https://platform.deepseek.com> 注册充值后创建）
4. 点击 **测试连接** —— 成功后自动保存

## 📖 使用方法

| 操作 | 说明 |
|------|------|
| 选中文字 | 出现悬浮球，点击即翻译 |
| 右键菜单 | 选中文本 →「Translate selection with Astra」 |
| `Alt+T` | 快捷键翻译选中文本 |
| 扩展图标 | 打开弹窗，手动输入 / 粘贴翻译 |
| 整页翻译 | 弹窗 →「翻译当前页面」；「还原当前页面」恢复原文 |
| 查词 | 选中单词，弹窗显示词性 / 释义 / 例句 / 发音 |

## ⚙️ 设置项一览

| 分类 | 设置项 | 默认值 | 说明 |
|------|--------|--------|------|
| 服务商 | 预设 / Base URL / Endpoint / 模型 / API Key | DeepSeek · `deepseek-v4-flash` | OpenAI 兼容接口 |
| 服务商 | 关闭思考 | 开 | 对支持思考的模型可关闭，提速省钱 |
| 翻译 | 默认 / 页面 / 划词目标语言 | 简体中文 | 三套独立配置 |
| 翻译 | 温度 | 0.2 | 越低越稳定 |
| 翻译 | 智能目标语言 | 开 | 自动判断翻译方向 |
| 翻译 | 第二目标语言 / 智能判断最大字符数 | English / 40 | 短文本反向翻译 |
| 翻译 | 同语言转第二语言 / 最低纯度 | 开 / 0.82 | 避免“同语种互译” |
| 翻译 | 词典模式 | 开 | 短词显示词性 / 释义 / 例句 |
| 翻译 | 超时 / 批量大小 / 并发数 | 30s / 4000 / 2 | 整页翻译性能调节 |
| 翻译 | 实时翻译 | 开 | 跟进动态 / 懒加载内容 |
| 悬浮球 | 开关 / 大小 / 透明度 | 开 / 48px / 80% | |
| 悬浮球 | 弹窗缩放 | 100% | 80%–180% |
| 提示词 | 划词 / 整页提示词 | 内置默认 | 自定义翻译文风，支持 `{{targetLang}}` 占位符 |

> 翻译缓存为内置能力，默认开启（约 5000 条、LRU 淘汰），无需手动配置。

## 🔒 隐私

- 翻译文本仅发送到 **你自己配置** 的 API 服务商
- 扩展不收集、存储或上传任何用户数据
- API Key 存储于 `chrome.storage.local`，绝不发送给第三方
- 密码输入框与代码块不参与翻译

## 🛠 技术栈

- **TypeScript** + **React 18**（弹窗 / 设置页）
- **Vanilla DOM** 内容脚本（零运行时依赖，体积小、注入快）
- **Vite 5** 构建
- **Chrome Manifest V3**

## 📁 项目结构

```
src/
├── background/     # Service Worker（消息路由、API 调用、翻译缓存）
├── content/        # 内容脚本（划词、悬浮球、弹窗、整页翻译）
├── popup/          # 弹窗 UI（React）
├── options/        # 设置页 UI（React）
├── shared/         # 共享模块（类型、i18n、prompts、语言检测、存储）
└── styles/         # 主题变量
```
