## 为什么是 Astra？

市面上的翻译插件，要么逼你登录、买会员、限次数，要么塞满广告。
Astra 反着来：**它不绑架你，只做一件事——把翻译做好。**

- 🔑 **用你自己的 API** —— 接入 Google Gemini (AI Studio)、DeepSeek 等大模型，按量付费或使用免费额度，成本极低
- 🚫 **无登录 / 无会员 / 无广告** —— 装上填个 Key 就能用
- 💸 **本地缓存复用** —— 命中缓存时直接读取结果，不再调用模型；旧缓存会按容量和使用情况淘汰
- 🎨 **翻译文风可调** —— 让 AI 用你喜欢的语气翻译，这是传统翻译引擎给不了的
- 🔒 **隐私优先** —— API Key 只存在你本地，各服务商配置独立隔离保存

## ✨ 功能特性

### 多种翻译方式
- **划词翻译** —— 选中文字即出悬浮球，一点就翻，弹窗可自由拖拽
- **右键翻译** —— 右键菜单一键翻译选中文本
- **快捷键** —— `Alt+T` 翻译当前选中内容
- **整页翻译** —— 一键翻译整个页面，边翻边看、随时可中断还原
- **手动翻译** —— 点开弹窗，粘贴任意文本即时翻译

### 漫画与图片沉浸式 AI 翻译（v6.0 重磅全新功能）

v6.0 全新打造的沉浸式漫画翻译系统，将多模态大模型的视觉理解能力带入漫画阅读场景。支持右键单图翻译、`Alt+M` 自由选图截字，或在漫画阅读网站中一键开启沉浸式漫画工具栏：

- **智能画幅识别与对开页（Spread）支持** —— 自动识别单页、跨页对开双拼大图以及长条漫，智能分块处理并剔除无关外链广告，还原无缝视觉。
- **全自动连续翻页（Auto Continuous Mode）** —— 翻页或向下滚动时，后台自动检测并翻译下一页或新进入视口的画面，无需反复手动点击。
- **高并发多线程预读流水线** —— 支持后台并发预读 **1 ~ 5 页**（默认 2 页，支持 1~6 个并发线程可调），提前在后台准备好后续翻译，翻页瞬间零等待立刻呈现译文。
- **沉浸式阅读调整弹窗（Reader Hub Modal）** —— 工具栏点击「⚙ 调整」即可就地展开深色磨砂玻璃卡片：
  - 头部内嵌 `[ A- ] [ 100% ] [ A+ ]` 精细界面缩放与关闭按钮；
  - 一键切换预读深度 `[ 1页 ] [ 2页 (推荐) ] [ 3页 (极速) ]` 与状态实时监控；
  - 常用阅读操作集：`[ 👁 原图对比 ]`、`[ ✂ 自由选图 Alt+M ]`、`[ ↺ 重新翻译 ]`、`[ ≡ 全部译文对照 ]`；
  - `[ ⇋ 切换横向/竖向 ]`：自由在底部横向悬浮岛与侧边竖栏之间切换，绝不遮挡漫画正文分镜；
  - `[ 💊 收起为边缘胶囊 ]`：专心看漫时一键最小化为边缘小胶囊（`⚡ 自动中 · 2P`），让出全屏画幅。
- **界面无级缩放（UI Scale 0.75x ~ 1.6x）** —— 工具栏常驻 `[ 100% ]` 快捷键，一键循环切换 `100% → 120% → 140% → 85%`，专门解决 2K / 4K 高分辨率大屏下字体和按钮过小费眼的问题，缩放比例自动持久化保存。
- **智能排版与气泡折叠** —— 根据气泡形状自适应横排或竖排排版，复杂背景或超长译文自动生成折叠卡片，鼠标悬浮即可预览原文与多译文对照。

[漫画翻译设置与使用说明](docs/manga-translation.md) · [架构文档](docs/manga-translation-architecture.md)

### 实时同声传译 / 网页悬浮字幕（Live Subtitles）
切换至「同传」标签页，通过 Web Speech API 实时识别音频并进行流式双语翻译。
- **悬浮字幕 HUD** —— 网页上浮动半透明悬浮字幕框，看生肉视频、外语直播、听会议演讲的绝佳助手
- **实时流式呈现** —— 边说边出字，自动跟随滚动，支持原文与译文双语对照显示
- **导出与拷贝** —— 会话记录随时一键复制，关闭即清空

### 智能省心（默认开箱即用）
- **智能目标语言** —— 选中英文自动翻成中文，选中中文自动翻成英文，无需手动切换方向
- **同语言纯度判断** —— 自动避免“中译中”这类无意义翻译，不浪费 token
- **软 / 硬内容保护** —— 自动识别链接、邮箱、路径、代码、哈希值并跳过；用户名 / ID 保持原样不被翻乱；密码输入框、代码块永不参与翻译
- **持久化缓存** —— 内置 SHA-256 去重缓存（默认 5000 条、4 MiB 预算，LRU 淘汰），命中时无需再次调用模型
- **实时增量翻译** —— 整页翻译时自动跟进动态加载、滚动懒加载出来的新内容

### 词典模式
选中单词或短语时，不只是翻译，还会给出 **词性、常见释义、当前语境说明、例句、发音**，并能识别人名 / ID 并保持原样——查词、背单词、读外刊的利器。

### 页内 AI 对话与前台即时切模
选中文字点 💬，或右键悬浮球选「问 AI 这个页面」，对话面板**直接开在网页里**，不用跳去插件弹窗、也不会打断你正在读的东西。面板可拖拽、可缩放，`Esc` 关闭。

- **前台一键换模型** —— 在对话底栏点击模型胶囊即可随时切换（Gemini 3.7 Flash、DeepSeek V4 等），免去来回跳转设置页
- **原生推理强度** —— 各服务商原生档位细分适配（Gemini: `off / low / medium / high`，DeepSeek: `off / high / max`）
- **自动读懂当前页** —— 打开对话时自动提取页面正文（按正文密度打分，跳过导航 / 页眉页脚 / 侧栏），顶部显示可一键移除的引用条；不想带就点 ✕，也可在设置里全局关闭
- **重新生成** —— 回答不满意，↻ 一下换个说法，不用重打问题
- **联网补充** —— 可选开启，先搜再答并附上来源
- **会话隔离** —— 弹窗保留私有会话，各网页文档使用各自的聊天记录，避免把其他页面或弹窗的内容显示给当前网站
- **会话与图片存储** —— 文字记录保留在浏览器会话中；图片存入有容量和过期控制的本机缓存。清空对话会清理关联图片，后台启动时清理失去会话引用的图片

### 高度可定制
- **三套独立目标语言** —— 整页翻译、划词翻译、默认翻译可分别设定语言
- **自定义提示词（文风）** —— 划词与整页的翻译提示词均可编辑，调出正经、地道、活泼、学术等任意风格
- **界面随心调** —— 悬浮球大小 / 透明度、弹窗缩放、并发数、批量大小、超时、温度均可设置

### 服务商中立与独立隔离存储
内置 **Google Gemini (AI Studio)**（支持 `gemini-3.7-flash` 免费层级）与 **DeepSeek** 官方预设，并支持任何 **OpenAI 兼容** 的 API（OpenAI、Groq、本地模型等）。各服务商的 API Key 与自定义模型配置**完全独立隔离存储**，切换时互不覆盖。

### 体验细节
- **iOS 18 液态玻璃设计** —— 超高饱和度毛玻璃折射、镜面高光光泽边缘、iOS 原生分段胶囊与灵动岛顶部悬浮通知
- **三语界面** —— 简体中文 / English / 日本語
- **自动暗色模式** —— 跟随系统主题
- **设置自动保存** —— 改动即存，测试连接成功自动落盘
- **20 种目标语言** —— 中、英、日、韩、法、德、西、俄、阿拉伯语等

## 🚀 快速开始

### 方式一：使用打包好的安装包（推荐普通用户）

1. 下载随附的安装包并 **解压**（解压后会看到包含 `manifest.json` 的扩展文件夹）
2. 打开浏览器扩展页：Chrome 输入 `chrome://extensions`，Edge 输入 `edge://extensions`
3. 打开 **开发者模式**
4. 点击 **加载已解压的扩展程序**，选择解压出来的扩展文件夹

> ⚠️ 浏览器无法直接加载 `.zip`，请务必先解压再加载文件夹。

### 方式二：从源码构建（开发者）

```bash
npm install
npm run build
```

构建产物在 `dist/`，再按「方式一」的第 2–4 步加载 `dist` 文件夹即可。

### 配置 API

1. 点击扩展图标 →「打开设置」⚙️
2. **服务商预设** 选择 **Google Gemini (AI Studio)**、**DeepSeek** 或自定义服务
3. 填入 **API Key**：
   - Google Gemini: 在 <https://aistudio.google.com/apikey> 免费获取
   - DeepSeek: 在 <https://platform.deepseek.com> 创建
4. 点击 **测试连接** —— 成功后自动保存，每个服务商的配置独立隔离存储

## 🔒 隐私

- 翻译文本仅发送到 **你自己配置** 的 API 服务商
- 扩展不收集、存储或上传任何用户数据
- API Key 存储于 `chrome.storage.local`，绝不发送给第三方
- 密码输入框与代码块不参与翻译
